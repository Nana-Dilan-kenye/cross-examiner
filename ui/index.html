Published coverage figures for the same country, antigen and year often disagree. Cross-Examiner reads each figure with its lineage, counts figures that share one origin as one, checks administrative figures against independent household measurements, and returns a recommendation or an explicit REVIEW for a person to decide.

Cross-Examiner supports human decision-making. It does not independently certify which vaccination figure is true.
